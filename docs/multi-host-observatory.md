# 原有观测台的多主机支持

观测台默认合并 Paseo 已接入的全部机器，不提供机器切换或机器筛选。沿用会话、看板、Token、明细、横评、事件流、归档和定时运行。智能分析已由 main 移除，本轮保留该变更。

## 入口和数据

每台机器安装同一插件后，本机后台采集本机数据。客户端复用 Paseo 的认证连接，按主机身份建立 RPC 注册表。会话目录和统计均通过该机器的插件后台读取；原生目录订阅用于实时更新，订阅不可用时按周期刷新。每台实例注册稳定且独立的内部页面 ID，侧栏名称保持一致并由 Paseo 合并为一个入口。每个具体页面只有一个安装来源，因而不显示机器下拉框；所有这些页面均汇总全机数据。旧地址通过兼容跳转进入对应页面。工作区和单会话检查面板保留各自对象范围。

原列表直接显示全部来源，会话行标明机器。详情、回复、审批、归档、改名、心跳、时间线、图片等使用带主机身份的实体 ID 路由，发送到后台前还原原始 ID。同名项目保持独立，并带来源名称；不会仅凭名称把不同目录误认成一个项目。

## 过滤、统计与去重

业务筛选包括项目、Provider、模型及各面板原有时间范围。机器范围固定为全部机器。统计和 Token 后端先筛选完整维度数据，客户端汇总完整排行、时间序列和样本分子分母，不相加各机器已经截断的 Top N，也不平均各机平均值。

活跃日期取并集，连续天数重新计算。Token 分类保持原有口径；响应速度由总输出和总耗时计算，分位数由合并的直方图计算。实时流速先按调用指纹去重，再按共同时间桶重算。

历史复制日志只有在调用指纹和计数均一致后才去重。后台生成临时排除投影，不修改任何机器的原始账本。历史指纹缺失、解析失败、正在变化的调用或超出核对预算会提示去重覆盖不足。相同账号键的额度取最新读数，不累加额度。

## 缺数及历史限制

离线、版本不兼容或读取失败时，其余机器仍返回数据，并标出缺失来源；保留的历史值带采集时间。实时汇总不计入离线缓存；列表保留的上次会话状态会标明机器离线。不同日期窗口的缓存不能混入当前窗口。连接更换后的旧响应不能覆盖新连接数据。

原有历史数据没有保存完整的并发时间区间：机器活跃时长按机器累加，历史并发显示各机已观测峰值的下界，不能解读为精确的全机峰值。按维度过滤时，只使用保留的会话小时记录；没有历史归因的工具名称和速度分位数不显示。

客户端页面依附一个 Paseo 主机。其他机器重连不会注销这个页面。页面所在主机断开时，Paseo 可能暂时显示不可用；重连后可在原地址恢复，也可点击同一个侧栏入口选择在线实例继续查看数据。历史缓存保存在客户端内存，不构成独立的离线数据库。

## 主机面板

工具栏右上角的「主机」入口列出 Paseo 已连接的每台主机，以及观测台在那台主机上的状态：最新、可更新、更新中、失败、离线，或没有运行中的观测台。所有主机都正常时入口显示版本号，否则显示待处理数量；手机上只在需要处理时出现，平时从「⋯」菜单进入。

- 全部更新：以当前页面所属安装能拿到的版本为目标，逐台调用各主机自己的审阅式更新。先更新其他主机，最后更新当前页面所属的那台，因为它的重启会重新加载面板。预览出的版本与目标不同的主机不强推，并注明原因。
- 安装：确认弹框展示将执行的命令后，在目标主机的一个工作区里打开终端，执行 `paseo plugin add <当前安装的来源>`；如果那台主机已配置过该插件（被禁用或启动失败），改为 `paseo plugin enable agent-observatory` 和 `paseo plugin update agent-observatory --yes`，保留它原来的来源。Windows 主机经 cmd.exe 执行，其他主机经 /bin/sh。成功后关闭终端；失败时保留终端，并在面板里显示输出末尾与手动执行的命令。
- 设备不读取任何主机的 daemon 配置（其中含有 provider 凭据）。在线超过 10 秒仍未注册插件实例的主机，视为没有运行中的观测台。
- 可以忽略某台主机：它仍然列出，但不再提示，也不参与「全部同步」。

## 安装和维护

源码：`paseo/plugins/dashbord/`；安装快照：根目录 `dashbord/`。仓库公开，安装不需要 Git 凭据。

```sh
paseo plugin add git:myaier/capibara:dashbord
# 已安装本仓库的同 ID 插件：
paseo plugin update agent-observatory --ref main
```

无 ref 的 Git 安装跟随默认分支，不会自动解析 GitHub 最新 Release；固定发布版本时使用 `--ref <tag或完整提交>`。

`npm run build` 生成生产 UI 分片，`npm run check:build` 校验。仓库根目录运行 `node paseo/scripts/package-plugin.mjs dashbord` 更新安装快照。实施契约和验收清单见 [开发验收清单](multi-host-todo.md)。

`observatory.host.diagnostics.get` 可核对已认证实例身份；`observatory.fleet.diagnostics.get` 返回客户端最近展示的数字汇总及其源机器计数，仅保存在内存，不记录消息或凭据。
