# 原有观测台的多主机开发与验收

当前状态：开发、合并、双机安装和核心实机验收已完成（`2.19.0-dev.5`），默认全机汇总，机器选择器已移除。各项证据层级见下表；真实业务会话的写操作没有作为测试执行。验收中的机器标识、安装记录和用量数值属于私密信息，只保存在本机，不进入仓库。

## 当前契约

- 沿用原来的会话、看板、Token、明细、横评、事件流等入口和布局，不增加独立首页或“本机工作台”。
- 移除 Paseo 观测台标题栏的机器切换入口；会话、卡片、事件、报告等保留来源主机标记。
- 各面板固定汇总全部机器；不保留主机多选或单机筛选。项目、Provider、模型、时间等条件在相应数据查询中实际生效。
- 单台缺数、离线、版本不兼容要显式表达；未知不等于零。详情和写操作只能作用于指定来源主机。
- 数据源：每台插件后台负责本机日志与统计，客户端复用 Paseo 已认证连接进行调度与汇总。
- 独立首页方案已被否决，不得恢复。安装状态以现场核验为准，不能用历史安装状态代替。

## 必须覆盖的场景

1. 两台机器有同名项目、相同会话/任务 ID，仍分别显示、正确下钻。
2. 打开观测台即显示 Mac + Windows 合并结果；所有标签、计数、图表一致，不出现机器选择器。
3. 单台离线、超时、缺少插件或版本过旧，其他主机继续可用，缺数不显示成零。
4. 切换筛选时旧响应迟到、连接替换、进入后台再回来，不能混入旧范围或残留订阅。
5. Token 输入/输出/缓存、加权 TPS、平均耗时、并发峰值、跨时区日期、全局 Top N。
6. 同账号、多机器日志副本、未关联会话、截断数据及历史采集起点。
7. 任何写操作只路由到所选实体；原界面上的详情、快捷操作及确认语义保留。

## 恢复入口

先读取本文件、`git status` 和最近提交，再核对运行中的插件提交。不得把旧独立首页方案当作已接受需求；不得把“会话跨主机已读到”当作全部面板完成。
