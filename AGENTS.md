# Agent instructions

This repository is public. Follow [CONTRIBUTING.md](CONTRIBUTING.md) for every commit:

- Run `git config core.hooksPath .githooks` once per clone before committing; do not bypass the hook (`--no-verify`).
- Never write real host names, IP addresses, Paseo server IDs, session/agent IDs, personal paths, email addresses, usage numbers or session content into tracked files, fixtures, docs or commit messages. Use fictional values (`WIN-DEMO-PC`, `srv_demo…`, `192.0.2.x`, `example.com`).
- Acceptance evidence and verification logs go to `.private/` (ignored), not `docs/`.
