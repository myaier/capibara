# 会话名称与右键菜单

版本：`2.18.0-dev.6`。开发源码位于 `paseo/plugins/dashbord`，安装快照为根目录 `dashbord`。保留当前原有面板布局；完整多主机面板仍按独立清单开发。

## 使用

会话行支持桌面右键、Shift+F10、手机长按和右侧“…”按钮。

- **重命名会话**：修改 Paseo 保存的会话名称，保存后重新读取确认。手动名称带来源标记，自动生成不会覆盖；如果其他客户端改了名称，会提示重新打开。
- **归档会话**：先展示归档对运行中会话、子会话和心跳的影响，确认后执行，并重新读取归档状态。取消不发写请求。
- 本次在原有主机作用域的会话列表提供操作。请求携带主机和原始会话 ID；服务端核对主机身份，不能误改另一台机器的同 ID 会话。未来多主机面板接入仍须通过独立路由验收。

这些操作不会修改 coding provider 独立保存的线程名称。

## 自动命名

打开会话列表后，插件在安装主机上异步处理临时标题。它读取最初的用户输入，只改空标题或与 Paseo 首条消息截取规则完全一致的标题；已有自定义标题、手动命名、已生成名称、归档会话及内部辅助会话跳过。首条输入不可确认时也保留原标题。Codex 会把 `/技能名 参数` 记为 `$技能名 参数`，而 Paseo 的临时标题取自发送时的斜杠形式，所以这两种写法视为同一个临时标题（2.18.0-dev.6 起）。

候选来自该主机已启用、状态为 ready 的 provider 模型目录。同 provider 优先，然后按 nano、Haiku/mini/Luna、Flash 等轻量系列排序，同档保留目录顺序。目录不提供统一的参数量或价格，所以这是轻量系列偏好，不声称能精确找出所有模型中最便宜的一个。未知模型不会凭名称猜出一个不存在的 ID，也不会降级到当前会话的大模型。

选择模型支持的最低推理档，最多尝试两个候选，每次生成限时 20 秒。输入仅含最多 2,000 字符的首条消息摘录，输出短标题；使用受限模式、无预批准工具的独立辅助会话，完成后归档。后台队列一次处理一个，不阻塞聊天。失败保留原标题。保存前再次核对名称和归档状态；手动改名会取消同会话的生成任务。

这里复用导入时已经进入 Paseo 的原生名称；尚未增加对外部 provider 改名事件的持续同步。

## 验证

- `tests/session-actions.test.ts`：持久化与读回、主机隔离、并发手动改名、归档竞态、已有名称保护、模型目录选择和失败回退。
- `tests/ui.spec.ts` 中 `session actions:`：右键和移动端入口、空名称、失败重试界面、取消/确认归档。
- 真实 Mac daemon 使用 GPT-6-Luna / low 完成独立命名样例（约 8.9 秒，包含创建会话）；同一验证会话完成重命名及归档读回。该结果验证服务调用，不代表已安装插件的界面已经更新。
